# Docs

This folder contains step-by-step usage guides for the ConVOLT codebase.

- `docs/quickstart.md`: minimal end-to-end commands (registration → UQ → tables → figures).
- `docs/installation.md`: Python environment + optional backends.
- `docs/datasets.md`: expected dataset layouts and notes per dataset/task.
- `docs/registration.md`: how to run each registration backend and interpret outputs.
- `docs/uq.md`: how to run uncertainty quantification and what is computed.
- `docs/tables_and_figures.md`: how to generate paper tables/figures from `uq_results/`.
- `docs/troubleshooting.md`: common failures and how to resolve them.
